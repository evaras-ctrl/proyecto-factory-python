# proyecto-factory-python
Proyecto con patrón Factory en Python.

Taller de control de versiones con Git y GitHub - Ingeniería de Software II (COM345), Universidad ECOTEC.

## Descripción

Proyecto en Python que implementa el patrón de diseño **Factory** para crear distintos tipos de notificaciones (Email, SMS, Telegram).

## Estructura del proyecto

proyecto-factory-python/
├── notificaciones/
│ ├── init.py
│ ├── base.py
│ ├── factory.py
│ └── servicios.py
├── main.py
├── .gitignore
└── README.md

## Ejecución

python main.py

## Flujo de trabajo aplicado

- Inicialización del repositorio con `git init` y rama principal `main`
- Commits con el estándar de Commits Convencionales (`feat:`, `fix:`, `docs:`)
- Trabajo en ramas independientes (`feature/notificacion-telegram`)
- Integración mediante Pull Request
